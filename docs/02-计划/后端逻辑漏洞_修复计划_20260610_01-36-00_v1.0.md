## 2. 影响评估与依赖

### 影响点分析
1. **SMTP 发送流程**（#1, #12）：影响已认证用户发送邮件时的 From 校验逻辑
2. **规则管理 API**（#2）：UPDATE 接口增加权限校验
3. **IMAP 协议层**（#3）：FindUE 增加用户隔离
4. **邮件删除**（#5, #13）：事务完整性和精确删除
5. **控制器层**（#6）：错误处理行为变更，解析失败立即返回
6. **API Token**（#7）：IP 比较逻辑修正
7. **附件下载**（#8）：Content-Disposition 头格式变更
8. **搜索功能**（#15）：搜索关键词转义
9. **文件夹管理**（#16）：DelGroup 增加用户隔离

### 风险评估
- 所有修复为局部修改，不涉及架构变更
- 管理员权限在所有修复中保持不受限制
- 单元测试和编译验证可确认无回归
