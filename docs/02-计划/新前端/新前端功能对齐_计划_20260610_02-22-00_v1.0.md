## 1. 目标与变更范围

### 要改什么
将新前端（`新前端构建/`）的功能与旧前端（`fe/`）对齐，修复以下功能差距：

1. **ComposeModal 发件人验证逻辑补全** — 添加 `@` 字符检查、至少一个收件人校验
2. **回信参数传递修复** — 传递完整回信参数（reply_sender, reply_domain），自动选择发件人域名
3. **发送成功后跳转发件箱** — 发送成功后切换分组到发件箱并刷新列表
4. **收件人输入改为标签式多选** — tag-input 替代纯文本 input，对齐旧前端 el-select multiple 体验
5. **CSV导入支持选择目标字段** — To/Cc/Bcc 选择
6. **iframe 高度自适应** — 监听 iframe 内容高度变化，动态调整

### 不改什么
- 不替换编辑器（contenteditable → WangEditor），后续单独处理
- 不改变新前端整体布局架构（三栏式保持不变）
- 不引入 Element Plus 框架

## 2. 影响评估与依赖

### 影响点
| 文件 | 影响 |
|------|------|
| `新前端构建/src/components/ComposeModal.vue` | 验证逻辑、回信参数、CSV目标字段、tag-input |
| `新前端构建/src/views/HomeView.vue` | 回信参数传递、发送后跳转发件箱 |
| `新前端构建/src/components/ContentPanel.vue` | iframe 高度自适应 |

### 风险
- **tag-input 自实现**：需处理键盘事件（回车添加、退格删除）、输入验证等，有一定复杂度
- **iframe 高度**：sandbox 模式下可能存在跨域限制导致无法读取内容高度
- **回信参数**：需确保域名在用户允许列表中才自动选择
