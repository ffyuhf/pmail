## 1. 目标与变更范围

### 要改什么：
- 在 `新前端构建/` 文件夹内创建完整的新前端项目（Vue 3 + TS + Vite）
- 将旧前端 `fe/` 的全部 15 个功能模块迁移到新前端，采用参考 HTML 的极简 Apple 风格设计
- UI 层从 Element Plus 替换为自定义纯 CSS 组件
- 布局从 Docusaurus 风格改为三栏式（图标导航 68px + 列表面板 340px + 内容面板）

### 不改什么：
- 后端 `server/` 代码不做任何修改
- 旧前端 `fe/` 代码不做任何修改
- API 接口协议不变
- 参考文件 `新前端构建/新前端实现标准.html` 保留不动
