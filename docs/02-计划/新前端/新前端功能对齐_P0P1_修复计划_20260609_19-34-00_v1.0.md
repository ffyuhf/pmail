# 新前端功能对齐 P0/P1 修复计划

## 1. 目标与变更范围

### 1.1 目标
将旧前端 (fe/) 的全部现有功能迁移到新前端 (新前端构建/)，确保新前端功能完整性与旧前端一致。

### 1.2 变更范围（要改什么）
- **P0**（功能缺失，必须修复）：
  - RuleSettings 重写（条件编辑器 + 4种动作配置 + 编辑功能）
  - UserManagement 补全（编辑用户对话框 + 禁用开关 + 分页）
  - GroupSettings 重写（树形结构 + 子文件夹创建）
  - ComposeModal 发件人选择器（域名+前缀+昵称 Popover，需后端数据）
  - 路由守卫（登录检查）
  - ListPanel 垃圾箱强制删除 (isTrashGroup)
  - ContentPanel 回信按钮（仅 type===0 显示）
- **P1**（体验补全）：
  - ContentPanel 收件人 JSON 解析显示
  - PluginSettings iframe 嵌入
  - MoveModal 叶子分组过滤

### 1.3 不改什么
- ❌ 分页控件 → 新前端使用无限滚动
- ❌ WangEditor → 新前端使用 contenteditable
- ❌ el-select multi → 新前端使用文本输入
- ❌ 头像首字母 → 非必要增强

- PluginSettings iframe 依赖后端 /api/plugin/settings/{name}/index.html

## 4. 回滚方案与失败判定

### 4.1 回滚方案

### 4.2 失败判定
- 编译错误 → 立即修复
