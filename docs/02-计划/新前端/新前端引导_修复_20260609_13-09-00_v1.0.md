### 影响点：
- **新前端引导功能从不可用变为可用**：当前新前端的 setupService 使用了不存在的 API 端点，所有引导请求均会失败

- **风险低**：后端 API 协议稳定，旧前端已验证可用，新前端仅需对齐

### 依赖：
- 后端 `POST /api/setup` 端点（`server/controllers/setup.go`）
- 后端 Setup Token 机制（`server/config/config.go`）
- setup_server 路由注册（`server/listen/http_server/setup_server.go`）
