## 1. 目标与变更范围

### 要改什么

1. **BUG-1：邮箱地址输入需回车确认**  
   - 当前：`TagInput.vue` 只在按回车/逗号/分号时才添加标签  
   - 期望：输入框失焦（blur）时自动将输入内容识别为标签；标签文本可点击进入编辑模式

2. **BUG-2：收信地址过多时 CSV导入等按钮变大**  
   - 当前：`.row-input-wrap` 使用 flex 默认 `align-items: stretch`，TagInput 高度撑大时按钮被拉高  
   - 期望：按钮保持固定大小，TagInput 区域出现滚动条

3. **BUG-3：邮件详情头部纯文本格式不好看**  
   - 当前：`ContentPanel.vue` 邮件头部为简单文本行（`发件人admin <admin@opi.local>`）  
   - 期望：对齐旧前端卡片式布局（头像 + 发件人/收件人/时间），CC 为 null 时隐藏

### 不改什么

- 不修改后端代码
- 不修改旧前端（fe/）代码
- 不修改邮件发送逻辑
- 不修改 CSV 导入解析逻辑

## 2. 影响评估与依赖

### 影响点

| 影响组件 | 影响说明 | 风险等级 |
|----------|---------|---------|
| `TagInput.vue` | 新增 blur 事件和标签点击编辑，可能影响 ComposeModal 中 TagInput 的交互 | 低 |
| `ComposeModal.vue` | 仅修改 CSS flex 对齐方式，无逻辑变更 | 极低 |
| `ContentPanel.vue` | 重构模板和样式，新增 parseContacts 方法和 getInitial 方法 | 低 |

### 依赖

- `TagInput.vue` 被 `ComposeModal.vue` 引用（To/Cc/Bcc 三个实例）
- `ContentPanel.vue` 的 `formatContacts` 函数需要改造为返回数组而非字符串

### 风险

- blur 自动识别：点击页面其他按钮时也会触发 blur，需确保不会产生意外行为
- 标签点击编辑：需正确处理从标签文本到输入框的焦点转移
