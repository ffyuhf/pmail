## 1. 目标与变更范围

### 要改什么

将新前端 4 个组件的视觉样式对齐「新前端实现标准.html」：

1. **IconNav.vue** — 按钮改圆形、compose 黑色圆形+阴影、添加用户头像、结构调整为 nav-top/nav-bottom
2. **ListPanel.vue** — 添加文件夹标题、邮件圆形头像、未读样式增强(font-weight:800)、选中左侧竖条、搜索框 focus 阴影
3. **ContentPanel.vue** — 添加独立工具栏、主题字号 28px+letter-spacing、内容区 max-width:800px 居中
4. **ComposeModal.vue** — 遮罩层 backdrop-filter:blur + 入场动画、弹窗宽度 600px、头部灰色背景

### 不改什么

- 功能逻辑（API 调用、状态管理、事件处理）
- 路由、服务层、类型定义
- 保留实际比标准更完善的功能：group-tabs、批量操作、checkbox、发件人 Popover、TagInput、CSV导入、附件上传、安全警告、iframe 沙箱

## 2. 影响评估与依赖

- **影响点**: 仅 CSS 样式和少量模板结构调整，不影响数据流和 API
- **风险**: 低风险，纯视觉调整，可通过浏览器直接验证
