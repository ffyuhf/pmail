# 新前端文件夹国际化 & 重复显示修复 & 发件人修复 计划书

> **版本**: v1.0  
> **日期**: 2026-06-09  
> **时间**: 22:19:00
> **作者**: PMail Team
> **模块**: 新前端
> **状态**: 已批准

## 1. 目标与变更范围

### 1.1 要改什么
1. **默认邮箱文件夹名称国际化**：前端显示名称根据语言设置替换，实际文件夹名不变
2. **最左栏文件夹重复显示**：硬编码默认文件夹与后端返回的默认文件夹重复，需匹配隐藏
3. **发件人地址前缀无法设置**：ComposeModal 发件人 popover 无法正常操作（CSS 定位 + 交互问题）

### 1.2 不改什么
- 后端代码不做任何修改
- 文件夹实际名称（存储名）不变
- 旧前端代码不变

## 2. 影响评估与依赖

### 2.1 影响范围
- `新前端构建/src/utils/constants.ts` — 新增默认文件夹映射表
- `新前端构建/src/i18n/index.ts` — 补充 i18n key
- `新前端构建/src/components/IconNav.vue` — 重构 quickGroups
- `新前端构建/src/components/ListPanel.vue` — group tabs i18n 替换
- `新前端构建/src/components/ComposeModal.vue` — 修复 popover 定位

### 2.2 风险评估
- **低风险**：所有修改均为前端展示层逻辑，不涉及后端接口变更
- **注意点**：tag 字符串匹配需解析 JSON 后按 type+status 匹配，不能直接字符串比较

## 3. 实施步骤与检查点

### 步骤1: constants.ts — 定义默认文件夹映射
- 定义 `DEFAULT_FOLDERS` 常量数组（5个默认文件夹）
- 每项包含：tag 匹配条件（type+status）、i18n key、图标
- 提供 `isDefaultGroupTag(tag)` 函数判断是否默认文件夹
- 提供 `getDefaultFolderLabel(tag)` 函数获取 i18n 名称

### 步骤2: i18n/index.ts — 补充缺失 key
- 补充：all_email、sketch、junk、deleted

### 步骤3: IconNav.vue — 重构 quickGroups
- 硬编码完整 5 个默认文件夹（收件箱、发件箱、草稿箱、垃圾箱、已删除）
- flatGroups 过滤掉所有默认文件夹（通过 isDefaultGroupTag 匹配）
- 默认文件夹名称使用 i18n

### 步骤4: ListPanel.vue — group tabs i18n 替换
- 渲染时判断是否默认文件夹，是则用 i18n 名称替换

### 步骤5: ComposeModal.vue — 修复发件人 popover
- 修复 .row-input-wrap 添加 position: relative
- 修复 popover 层叠上下文和溢出裁剪
- 对齐旧前端管理员权限控制

### 检查点
- [ ] 默认文件夹在不同语言下显示正确名称
- [ ] 最左栏不出现重复文件夹
- [ ] 发件人 popover 可以正常打开、选择、关闭
- [ ] 管理员可编辑发件人前缀，非管理员禁用

## 4. 回滚方案与失败判定

### 回滚方案
- 所有修改均为单文件局部修改，可通过 git revert 逐个回滚

### 失败判定
- 默认文件夹名称仍显示未翻译 → 失败
- 最左栏仍有重复文件夹 → 失败
- 发件人 popover 无法打开或关闭 → 失败
