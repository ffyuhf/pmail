## 1. 目标与变更范围

- **要改什么**：将 IconNav / ListPanel / ContentPanel / ComposeModal 四个组件的 CSS 视觉参数（尺寸、字号、间距、圆角、动画）精确对齐「新前端实现标准.html」
- **不改什么**：
  - 所有功能逻辑代码（script 部分）不动
  - 增强功能（批量操作、分组标签、多选框、iframe 渲染等）全部保留
  - HTML 结构/模板不变

## 2. 影响评估与依赖

- **影响点**：仅影响视觉呈现，不影响功能行为
- **风险**：低风险，纯 CSS 属性调整
- **依赖**：variables.css 被所有组件引用，需优先修改

## 3. 实施步骤与检查点

- [ ] 步骤1：修改 `variables.css`（--icon-nav-width: 56px, --list-panel-width: 260px）
- [ ] 步骤2：修改 `IconNav.vue` 样式（按钮 36×36 圆角方形、头像 28×28、图标改 +、active 黑底白字、缩放反馈）
- [ ] 步骤3：修改 `ListPanel.vue` 样式（缩小全部字号/间距/头像 32×32、交错动画、hover 平移）
- [ ] 步骤4：修改 `ContentPanel.vue` 样式（缩小 padding/主题 20px/头像 36×36、内容切换动画）
- [ ] 步骤5：修改 `ComposeModal.vue` 样式（弹窗 480px、缩小 padding/字号、修改入场动画）
- [ ] 步骤6：创建代码修改文档
- [ ] 步骤7：更新变更日志
- [ ] 步骤8：构建验证 `npm run build`

## 4. 回滚方案与失败判定

- **回滚方案**：git revert 本次所有 CSS 变更
- **失败判定条件**：构建失败、功能逻辑被误改、增强功能丢失
