## 1. 目标与变更范围

### 要改什么：

根据对照后端 Go 服务器实际路由和旧前端参考实现，修复新前端中与后端 API 协议不一致的地方：

1. **axios 拦截器**：补充 POST 自动 JSON.stringify、响应数据解包、路由导航改用 vue-router
2. **emailService.ts**：修正 `getEmailList` 参数名（`groupTag→tag`, `page→current_page`, `pageSize→page_size`），`sendEmail` 从 FormData 改为 JSON 格式（base64附件），修正附件下载URL为 `/attachments/download/`
3. **userService.ts**：修正 `logout` 端点（`/api/login→/api/logout`），`changePassword` 参数名（`new_password→password`），`getUserList` 参数名（`page→current_page, page_size`），`createUser` 参数名（`name→username`, `is_admin→disabled`），删除不存在的 `deleteUser` 接口
4. **groupService.ts**：删除后端不存在的 `updateGroup` 接口
5. **HomeView.vue**：适配修正后的 emailService 和 groupService 调用方式
6. **ComposeModal.vue**：发送格式从 FormData 改为 JSON（base64 附件），附件读取方式调整
7. **settings 组件**：修正 `changePassword` 参数、`createUser` 参数、移除 `deleteUser`/`updateGroup` 调用

### 不改什么：

- 后端 `server/` 代码不做任何修改
- 旧前端 `fe/` 代码不做任何修改
- UI 样式和布局保持新前端现有设计不变
- 功能增强（如富文本编辑器）后续迭代处理，本次仅修复 API 协议对齐

## 2. 影响评估与依赖

| 影响区域 | 影响描述 | 严重程度 |
|----------|----------|----------|
| axios.ts | POST 请求未 stringify 导致后端无法解析 JSON | **致命** |
| emailService.ts | 参数名不匹配导致邮件列表/搜索失败 | **致命** |
| emailService.ts | sendEmail 用 FormData 导致后端解析失败 | **致命** |
| emailService.ts | 附件下载 URL 错误导致 404 | **高** |
| userService.ts | logout 端点错误导致无法正常退出 | **高** |
| userService.ts | 参数名不匹配导致用户管理功能异常 | **高** |
| groupService.ts | updateGroup 端点不存在导致报错 | **中** |
| HomeView.vue | 依赖 service 层，同步需要适配 | **高** |
| ComposeModal.vue | 发送格式需从 FormData 改为 JSON | **高** |

### 风险

| 风险 | 可能性 | 影响 | 缓解措施 |
|------|--------|------|----------|
| 组件内部有其他参数假设 | 中 | 中 | 逐文件检查所有 API 调用点 |
| 构建失败 | 低 | 高 | 每阶段验证 `npm run build` |
| CSV 导入组件不完整 | 中 | 低 | 标记为 TODO，后续迭代 |
