## 1. 目标与变更范围

### 要改什么
- 修复附件下载 URL 格式不匹配后端解析的问题
- 修复分组文件夹数量不正确（丢失子文件夹）的问题
- 修复设置面板大小随选项切换改变的问题
- 修复国际化硬编码英文字符串的问题
- 修复 moveEmails 缺少 group_name 参数的问题
- 修复设置面板用户管理标签未做管理员权限判断的问题

### 不改什么
- 不修改后端代码（后端协议已固定）
- 不修改旧前端（fe/）代码
- 不新增功能（仅对齐旧前端现有功能）

---

## 2. 影响评估与依赖

### 影响点
| 修改项 | 影响文件 | 影响范围 |
|--------|---------|---------|
| 附件 URL | `emailService.ts` | 邮件详情中附件下载链接 |
| 分组文件夹 | `stores/group.ts`, `IconNav.vue`, `HomeView.vue`, `ListPanel.vue` | 左侧导航和分组标签栏 |
| 设置面板大小 | `SettingsPanel.vue` | 设置弹窗 UI |
| 国际化 | `i18n/index.ts`, `ContentPanel.vue`, `ComposeModal.vue` | 多语言文本显示 |
| moveEmails | `emailService.ts`, `HomeView.vue` | 邮件移动功能 |
| 权限判断 | `SettingsPanel.vue` | 设置面板标签显示 |

### 风险
- **低风险**：所有修改均为前端 UI/逻辑修正，不涉及后端 API 变更
- **低风险**：各修改项相互独立，不会产生级联影响
