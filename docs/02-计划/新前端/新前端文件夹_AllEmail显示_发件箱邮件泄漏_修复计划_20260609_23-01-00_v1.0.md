## 1. 目标与变更范围
- 要改什么：
  - Bug1：默认邮箱文件夹"All Email"是父容器节点，不应显示在可选文件夹列表中
  - Bug2：发信箱里的邮件在收信箱也能看到（因为无 tag 节点导致后端查询不过滤 type）
  - DEFAULT_GROUP_TAG 与后端返回的 tag 不一致（缺少 group_id 字段）
- 不改什么：
  - 后端代码不修改
  - 旧前端代码不修改
  - 其他功能不变

## 2. 影响评估与依赖
- 影响点：
  - `stores/group.ts` flatGroups 计算属性 → 影响 IconNav、ListPanel、MoveModal 的文件夹列表
  - `utils/constants.ts` DEFAULT_GROUP_TAG → 影响默认选中状态
  - `components/IconNav.vue` quickGroups → 防御性检查
- 风险：低。仅过滤无 tag 的容器节点，不影响有 tag 的可选文件夹

## 4. 回滚方案与失败判定

- 失败判定条件：有 tag 的文件夹消失，或切换文件夹后邮件列表为空
