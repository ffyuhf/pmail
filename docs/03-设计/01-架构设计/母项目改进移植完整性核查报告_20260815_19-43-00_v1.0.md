## 1. 核查方法与口径

- **归一化对比**：将母项目全部 Go 文件 import 路径 `github.com/Jinnrry/pmail` 归一化为 `github.com/ffyuhf/pmail` 后，与现有项目 `server/` 全目录 `diff -r`，消除 import 噪音得到**实质差异文件清单（67 个）**；另比对根级构建文件（Makefile/Dockerfile/DockerfileGithubAction/.gitignore/README.md/.github/）。
- **母项目独有代码提取**：对 67 个差异文件逐个提取"母项目有而现有项目没有的非注释代码行"（共 939 行），作为潜在改进证据逐一判定。
- **三分类判定**：A（母项目改进 → 合并移植）/ B（现有项目自有增强或领先实现 → 保留不动）/ C（无实质差异：注释翻译、import 顺序、日志措辞 → 忽略）。
- **判定依据**：现有项目变更日志 v1.0~v2.6 全部历史（自有增强清单）+ 上轮移植计划书 MIG 清单 + 双侧文件全文比对。

## 3. B 类清单（现有项目自有增强/领先实现，保留不动，共 54 文件）

判定要点（母项目侧为旧版或等价弱化版）：

- **安全体系**：bcrypt 密码（`utils/password`、`controllers/login.go`、`listen/smtp_server/action.go`、`listen/imap_server/session_login.go`、`listen/pop3_server/action.go`）替代母项目双 MD5；ratelimit 暴力破解防护（pop3/imap）；强制 TLS 认证（pop3 STLS、smtp AllowInsecureAuth=false）；From 伪装拒绝与 Sender 伪造检测（`read_content.go`，覆盖母项目 `spoofed` 弱化逻辑）；Setup API Token 鉴权与 DSN 脱敏（`controllers/setup.go`、`config/config.go`）；XSS 净化 `stripHTMLTags`（修复母项目 strictPolicy 引号过度编码缺陷，`dto/parsemail/email.go` + `email_xss_test.go` 期望值配套）。
- **DSN 退信（RFC 3461）**：`services/dsn` 包 + `read_content.go` `sendDSNOnFailure` + SMTP `EnableDSN`/`EnableSMTPUTF8`（`listen/smtp_server/smtp.go`、`action.go`）。
- **结构化日志**：`utils/log` + `pmailLog` 全链路（smtp/imap/pop3/http 各协议事件）；`config.go`/`framework.go` 日志格式增强（getRealCaller/shortenFilePath/Protocol）。
- **API 精确化**：`ue_ids` 双通道（`controllers/email/{delete,move}.go` + `services/del_email` `DelEmailByUeIds` + `services/group` `MoveMailToGroup(ueIds)`）；`UeId`/`Type` 响应字段（`controllers/email/list.go`、`dto/response/email.go` MarshalJSON）；rule 控制器错误响应与 IsAdmin 分支；user 控制器 admin 禁用防护。
- **越权修复**：DeleteGroup 补 user_id（#16）、detail 查询补 user_id、read 控制器错误返回（#6）、attachments RFC5987 文件名与 CRLF 清理。
- **IMAP 增强**：Caps 公布修复（BUG-1/4/5/6/7 + LiteralPlus + ESearch）；`NewSession(remoteAddr)` 带 IP；session_copy 重复检查；session_move HasChildren 校验；session_idle 超时统计；`utils/context` 扩展字段（Protocol/ClientIP 等）。
- **Token 认证**：`models/api_token.go` + `https_server.go` 数据库 Token（替代母项目密码派生 5 秒 Token 弱方案）。
- **其他**：DKIM 2048/0600 权限（auth.go）、Cookie 安全加固（session/init.go）、Makefile arm64 构建、.gitignore 敏感文件隔离、res_init DkimGen/ratelimit 初始化、main.go 启动横幅。

## 5. 核查结论

1. **67 个实质差异文件全部处置完毕，零未处置**：5 个 A 类本次移植（含 1 项与上轮 doMove 强配套的查询侧缺失）、54 个 B 类保留、13 个（含 go.mod/CI）C 类忽略——处置结果见第 2~4 章及各代码修改文档。
2. **上轮（v2.6）MIG-01~MIG-09 移植经抽样复核全部在位**（`controllers/email/list.go` sender 回退与统一认证入口、`read_content.go` 认证防篡改、`rule.go` doForward/doMove、`send.go` ForwardRaw、spam_block 权限保护及 6 份测试均在）。
3. **母项目无遗漏改进**：归一化全量 diff + 母项目独有代码行逐行判定后，除上述 5 项外不存在"母项目改进且现有项目缺失"的内容；现有项目在安全（bcrypt/ratelimit/强制TLS/XSS/Token）、DSN、结构化日志、API 精确化等维度全面领先母项目。
4. **前端 `fe/` 与 `新前端构建/`**：母项目为 JS 旧版前端，现有项目为 TS 重写版，按计划书共识排除在移植范围外。
