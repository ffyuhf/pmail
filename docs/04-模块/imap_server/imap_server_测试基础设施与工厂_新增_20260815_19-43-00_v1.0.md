## 2. 变更原因与影响点

- **变更原因**：母项目测试基础设施改进——现有旧版测试依赖固定 993 端口（与生产端口冲突、CI 不可并行）、依赖 cwd、无种子数据、IDLE 空测；母项目版本使测试自包含可复现。
- **影响范围**：仅 `listen/imap_server` 包；`imap_server.go` 为结构性重排（工厂抽取），生产行为等价。
- **接口兼容性**：`NewSession(remoteAddr)` 沿用现有签名（适配现有 ratelimit 逻辑），未采用母项目无参旧签名。
- **性能**：无影响（生产路径同一逻辑）。
- **运行环境说明**：TestMain 仍依赖 `config/config.json` 与 SSL 证书文件，该包在当前仓库为 v2.6 已记录的预存环境性失败；基础设施就位后环境齐备即可运行（随机端口消除端口占用不确定性）。
