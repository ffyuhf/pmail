## 三、变更原因

修复 BUG-1/4/5/6/7：IMAP 服务器已实现 IDLE、NAMESPACE、UIDPLUS、MOVE、CHILDREN 功能，
但未在 Caps 中声明，导致客户端无法识别这些能力。

| BUG 编号 | 能力 | 影响 |
|----------|------|------|
| BUG-1 | IDLE | 客户端无法使用 IDLE 实时推送 |
| BUG-4 | NAMESPACE | 客户端无法识别命名空间扩展 |
| BUG-5 | UIDPLUS | 客户端无法利用 UID 增强操作 |
| BUG-6 | MOVE | 客户端回退到 COPY+DELETE+EXPUNGE |
| BUG-7 | CHILDREN | 客户端需额外 LIST 确定子文件夹 |

## 四、影响评估

- 接口兼容性：纯增量声明，不影响已有功能
- 性能：无影响
- 安全：无影响
