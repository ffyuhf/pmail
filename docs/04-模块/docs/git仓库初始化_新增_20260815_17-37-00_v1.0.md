## 2. 变更原因与影响点

- **变更原因**：建立本地版本控制基线，使后续开发可回滚（`git checkout`/`git revert`）、可审计；同时隔离敏感文件与冗余产物，防止误提交
- **影响范围**：仅 `PMail/` 目录（工作区根目录的 `PMail.zip`、`实验构建产物/` 位于仓库外，天然不受影响）
- **接口兼容性**：无影响（未触碰任何业务代码）
- **性能**：无影响（`.gitignore` 阻止 node_modules/dist/db 入库，仓库保持轻量）
- **安全**：正向提升——SSL 私钥、数据库密码、SQLite 数据均被排除在版本控制之外
- **远程约束**：纯本地仓库，`git remote` 数量为 0，未上传 GitHub（按用户要求，后续如需远程须另行评估）
