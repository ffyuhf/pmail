## 变更记录

### 2026-06-10 新前端功能对齐 P0/P1 修复（6 项功能差距）

| 编号 | 优先级 | 差距描述 | 修复文件 |
|---|---|---|---|
| #1 | 🔴 P0 | 发件人前缀 @ 检查缺失 | `ComposeModal.vue` |
| #2 | 🔴 P0 | 回信参数传递缺失（replySender/replyDomain） | `HomeView.vue`, `ComposeModal.vue` |
| #3 | 🔴 P0 | 收件人输入非标签式多选 | `TagInput.vue`（新增）, `ComposeModal.vue` |
| #4 | 🔴 P0 | 发送成功后未跳转发件箱 | `HomeView.vue` |
| #5 | 🟠 P1 | iframe 邮件正文高度不自适应 | `ContentPanel.vue` |
| #6 | 🟡 P2 | CSV 导入缺少目标字段选择 | `CsvImportModal.vue` |

### 修改详情

1. **ComposeModal.vue** — 发件人验证补全（@ 检查、至少一个收件人校验）；新增 `replySender`/`replyDomain` props 自动选择发件人域名；收件人/抄送/密送改用 TagInput 组件
2. **TagInput.vue**（新增）— 对齐旧前端 `el-select multiple filterable allow-create`：回车添加标签、退格删除、粘贴批量添加、去重
3. **CsvImportModal.vue** — 新增目标字段选择器（to/cc/bcc），`emit('import', emails, targetField)` 传递目标字段
4. **ContentPanel.vue** — 新增 iframe 高度自适应定时器（300ms 轮询 contentDocument.scrollHeight），watch 控制生命周期
5. **HomeView.vue** — `onReply` 从 `email.to` 解析当前用户邮箱提取 replySender/replyDomain；`onEmailSent` 发送成功后切换到发件箱
