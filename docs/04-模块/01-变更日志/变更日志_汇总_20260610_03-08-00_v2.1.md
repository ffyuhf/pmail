## 变更记录

### 2026-06-10 新前端 UI BUG 修复（3 项）

| 编号 | 优先级 | BUG 描述 | 修复文件 |
|---|---|---|---|
| #1 | 🔴 P0 | 邮箱地址输入后需回车确认，不能自动识别 | `TagInput.vue` |
| #2 | 🔴 P0 | 收信地址过多时 CSV 导入等按钮变大 | `ComposeModal.vue`, `TagInput.vue` |
| #3 | 🟠 P1 | 邮件详情头部纯文本格式不好看 | `ContentPanel.vue` |

### 修改详情

1. **TagInput.vue** — 新增 `@blur` 事件处理函数 `onBlur()`：失焦时自动将输入内容识别为标签（延迟 100ms 避免误触）；新增 `editTag()` 函数：点击标签文本可回填到输入框编辑；新增 `max-height: 120px; overflow-y: auto;` 防止标签过多时撑大容器；标签文本添加 `cursor: pointer` + hover 下划线提示可点击
2. **ComposeModal.vue** — `.row-input-wrap.with-actions` 添加 `align-items: flex-start;` 防止按钮被纵向拉伸
3. **ContentPanel.vue** — 邮件头部从纯文本改为卡片式布局：圆形头像（首字母）+ 发件人名称粗体 + 邮箱灰色 + 收件人 chip 标签 + 时间右侧显示；CC 为 null 时隐藏 CC 行；新增 `parseContacts()` / `getInitial()` 函数和 `parsedTo` / `parsedCc` 计算属性
