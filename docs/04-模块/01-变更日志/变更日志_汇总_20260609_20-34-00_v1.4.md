## v1.4 — 2026-06-09 20:34:00

### 新前端引导响应解包修复
- **模块**: `新前端构建/src/views/SetupView.vue`
- **类型**: 修正（Bug Fix）
- **描述**: 修复引导界面所有 API 回调的响应格式不匹配问题。axios 拦截器已解包 `response.data`，但回调仍用 `res.data` 二次访问，导致：
  - 错误处理为死代码，后端错误被静默吞掉
  - 域名保存后无法正确推进到 DNS 步骤
  - DNS/SSL 配置读取失败
- **影响范围**: 仅 SetupView.vue，不影响后端和其他视图
- **相关文档**:
  - 计划书: `docs/02-计划/新前端引导_响应解包修复_计划_20260609_20-30-00_v1.0.md`
  - 修改文档: `docs/04-模块/新前端/新前端引导_响应解包修复_20260609_20-33-00_v1.0.md`
