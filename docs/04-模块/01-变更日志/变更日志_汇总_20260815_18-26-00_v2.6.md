## 变更记录

### 2026-08-15 母项目代码改进移植（规则转发 / 邮件认证 / 安全防护）

将母项目（上游 `github.com/Jinnrry/pmail`）相对现有项目（`github.com/ffyuhf/pmail`）的代码改进以**合并式移植**同步到现有项目，保留现有项目 DSN 退信、From 伪装拒绝、Sender 伪造检测、结构化日志等自有增强。

| 编号 | 变更项 | 内容 |
|------|--------|------|
| MIG-01 | 邮件认证体系（parsemail） | 新增 `EmailAuthentication` 结构体与 `NewEmailAuthentication` 工厂函数；`Email` 新增 `Authentication` 字段；`NewEmailFromModel` 为收件邮件恢复认证结果 |
| MIG-02 | 转发头部重写（parsemail） | `ForwardBuildBytes` 增加 `forwardAddress` 参数：From=本地转发用户、Reply-To=原发件人、X-Original-From/X-Forwarded-By/X-Forwarded-To、References/In-Reply-To；保留现有 base64/charset 修复 |
| MIG-03 | ForwardBuildBytes DKIM 空指针保护 | `instance == nil` 时直接返回原始字节 |
| MIG-04 | 转发投递（send） | `Forward` envelope from 改为本地用户身份（修复 SPF 拒信）；新增 `ForwardRaw`（原始字节转发保留 DKIM 签名）与 `forwardData` |
| MIG-05 | 规则引擎重构（rule） | `DoRule` 增加 `rawEmailData` 参数；FORWARD 重写为 `doForward`（地址验证/本地域判断/本地用户幂等投递/账户级自环检测/原始转发优先）；新增 `doMove` 系统文件夹移动逻辑 |
| MIG-06 | 收信认证防篡改（smtp_server） | 收信流程三处设置/重置 `email.Authentication`（插件不得篡改认证结果）；`saveEmail` 增加收信/发件认证隔离；`DoRule` 调用传 `emailData` |
| MIG-07 | 列表接口修复（listview） | sender 空值回退 FromAddress/FromName；Dangerous 统一 `NewEmailAuthentication` 入口（语义等价） |
| MIG-08 | spam_block 权限保护（安全） | `SettingsHtml` save 分支新增管理员校验，非管理员返回 "No Access Privileges" |
| MIG-09 | 测试移植 | 移植 6 份测试：`email_authentication_test.go`、`email_forward_test.go`、`smtp email_authentication_test.go`、`rule_forward_test.go`、`framework_test.go`、`spam_block_test.go`（import 路径改为 ffyuhf） |
