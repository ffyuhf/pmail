## 1. 修改前后代码要点对比

文件：[`server/controllers/email/list.go`](../../../server/controllers/email/list.go)

| 位置 | 修改前 | 修改后 |
|------|--------|--------|
| 循环体 | `json.Unmarshal(email.Sender)` 后直接使用 | 新增 sender 空值回退：`sender.EmailAddress == ""` 时回退使用 `email.FromAddress`/`email.FromName` |
| Dangerous 计算 | `email.SPFCheck == 0 && email.DKIMCheck == 0`（简化逻辑） | `parsemail.NewEmailAuthentication(email.SPFCheck == 1, email.DKIMCheck == 1).Dangerous`（统一认证入口，语义等价） |
| import | 无 parsemail | 新增 `github.com/ffyuhf/pmail/dto/parsemail` |

保留项：`UeId`/`Type` 字段（现有项目自有增强）。

## 2. 变更原因与影响点

- **原因**：母项目改进。Sender 头缺失的邮件（常见于部分群发/旧邮件）在前端列表显示空发件人；统一认证入口避免认证逻辑在多个位置重复实现。
- **影响点**：`/email/list` 响应字段不变减（Dangerous 语义一致：SPF 与 DKIM 均未通过时为 true）；前端无兼容性影响。
