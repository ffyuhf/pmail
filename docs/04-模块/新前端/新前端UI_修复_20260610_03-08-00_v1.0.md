## 2. 变更原因与影响点

### 变更原因

1. **BUG-1**：邮箱地址输入后必须回车确认，用户期望点击其他区域自动识别
2. **BUG-2**：收信地址过多时 CSV 导入等按钮变大（flex 布局拉伸）
3. **BUG-3**：邮件详情头部为纯文本格式，体验差

### 影响范围

- `TagInput.vue`：所有使用该组件的地方（ComposeModal 的 To/Cc/Bcc）均受益于 blur 自动识别
- `ComposeModal.vue`：仅 CSS 变更，无逻辑影响
- `ContentPanel.vue`：模板重构，`formatContacts` 函数保留兼容

### 接口兼容性

- 组件 props/emits 无变更，接口完全兼容
- `TagInput` 的 `modelValue` 类型仍为 `string[]`

### 性能影响

- `parsedTo`/`parsedCc` 为 computed 属性，仅在 email 变化时重新计算，性能无影响
- `onBlur` 使用 100ms setTimeout，对性能无影响

### 安全影响

- 无安全影响
