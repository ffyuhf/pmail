## 2. 变更原因与影响点

### 变更原因
用户报告新前端存在以下问题：
1. 无法查看发送的文件（附件 URL 格式错误）
2. 邮箱文件夹数量不对（丢失子文件夹）
3. 设置面板大小随选项切换改变
4. 国际化部分文本显示英文
5. moveEmails 缺少 group_name 参数
6. 用户管理标签未做权限判断

### 影响范围
- 仅影响新前端（`新前端构建/` 目录），不涉及后端和旧前端

### 接口兼容性
- moveEmails 增加 group_name 参数：向后兼容（后端 moveRequest 已定义此字段）
- 附件 URL 从查询参数改为路径参数：对齐后端现有解析逻辑，无破坏性变更

### 性能影响
- flatGroups 为 computed 属性，仅在 groups 数据变化时重新计算，性能影响可忽略

### 安全影响
- 用户管理标签增加权限判断，提升安全性
