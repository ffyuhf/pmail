## 1. 修改前后代码要点对比

### 1.1 修改文件目录树

```
新前端构建/src/
├── services/
│   └── setupService.ts    ← 完全重写（API 协议修正）
└── views/
    └── SetupView.vue      ← 完全重写（功能对齐旧前端）
```

### 1.2 setupService.ts 修改要点

| 项目 | 修改前（错误） | 修改后（正确） |
|------|----------------|----------------|
| API 协议 | RESTful 多端点（GET/POST /api/setup/database 等） | 统一 POST /api/setup（action+step+token） |
| 函数导出 | 独立函数（checkSetup, setupDatabase...） | setupService 对象（与旧前端一致） |
| Token 传递 | 不支持 token 参数 | 所有函数接受 token 参数 |
| getParams | 不存在 | 新增 getSslDnsParams（DNS 挑战） |
| setPassword | 仅传 password | 传 account + password |

### 1.3 SetupView.vue 修改要点

| 项目 | 修改前（错误） | 修改后（正确） |
|------|----------------|----------------|
| 步骤数 | 5 步（无欢迎页） | 6 步（欢迎→DB→密码→域名→DNS→SSL） |
| 步骤顺序 | DB→域名→DNS→SSL→密码 | DB→密码→域名→DNS→SSL（与后端一致） |
| Token | 未实现 | route.query + window.location.search 兜底 |
| 管理员账号 | 无 | 新增 admin_account 字段 |
| PostgreSQL | 不支持 | 新增 postgres 选项 |
| 多域名 | 不支持 | 新增 multi_domain 动态添加 |
| SSL 类型 | 'auto'/'manual' 字符串 | '0'/'1'/'2' 数字字符串 |
| SSL 挑战 | 不支持 | 新增 http/dns 挑战选择 |
| DNS 挑战展示 | 不支持 | 新增 dnsChecking 状态和参数轮询 |
| 完成跳转 | router.push('/login') | 轮询 /api/ping 后 location.href 跳转 |
| 预加载 | 不支持 | 每步进入前预加载已有配置 |
| 已设置检测 | 不支持 | 密码已设置时禁用输入框 |

## 2. 变更原因与影响点

### 变更原因：
新前端引导功能完全无法使用。`setupService.ts` 使用了后端不存在的 RESTful 分离端点（如 `/api/setup/database`），所有 HTTP 请求均返回 404。`SetupView.vue` 的步骤顺序与后端 `setup.go` 控制器不匹配，缺少关键功能。

### 影响范围：
- **仅影响新前端引导功能**：修复后引导流程可正常完成初始化
- **无破坏性影响**：不修改后端和旧前端代码
- **接口兼容性**：完全对齐后端 `POST /api/setup` 协议
