## 2. 变更原因与影响点

### 变更原因

新前端服务层使用了 RESTful 风格的 API 端点（GET/PUT/DELETE + 复数路径），但后端 Go 服务器使用的是 POST + 单数路径风格。导致所有 API 调用返回 404，新前端完全无法与后端通信。

### 影响范围

- 新前端所有 API 调用全部修复
- 后端无需任何修改
- 旧前端 fe/ 无需修改

### 接口兼容性

- 所有 API 签名与后端 `server/controllers/*.go` 完全对齐
- HTTP 方法全部改为 POST（除 GET /api/group 和 GET /api/plugin/list）
- 参数格式对齐后端 JSON body 约定

### 性能影响

无性能影响，仅修复请求路径。

### 安全影响

无安全影响。
