## 2. 变更原因与影响点

### 变更原因
- 新前端（实验状态）的服务层和视图层与后端 Go 服务器实际 API 协议存在多处不一致
- 参数名不匹配（camelCase vs snake_case）导致后端无法正确解析请求
- 发送邮件格式错误（FormData vs JSON）导致发送功能完全失败
- 存在后端不支持的接口调用（deleteUser、updateGroup）
- axios 拦截器逻辑不完整导致路由跳转和响应解析异常

### 影响范围
- **仅新前端构建/src/**，不影响后端和旧前端
- 所有 API 调用现已与后端 `http_server.go` 路由表完全对齐
- 所有请求参数名与后端控制器结构体 JSON tag 完全一致

### 接口兼容性
- 无破坏性变更：所有修复均是为了与后端对齐，不影响外部接口
- 旧前端 fe/ 代码不受影响

### 性能影响
- 无负面影响（取消 FormData multipart 请求，改为更轻量的 JSON）
- 构建产物大小与修复前基本一致

### 安全影响
- 无负面影响（Token 存储、401 跳转等安全机制保持）
- 注销端点修正为正确的 `/api/logout`
