## 1. 修改前后代码要点对比

### 目录树
```
新前端构建/src/
├── utils/
│   └── constants.ts          ← 修改：新增默认文件夹映射表和匹配函数
├── i18n/
│   └── index.ts              ← 修改：补充 4 个国际化 key
├── components/
│   ├── IconNav.vue           ← 修改：重构 quickGroups，消除重复，应用 i18n
│   ├── ListPanel.vue         ← 修改：group tabs 应用 i18n 名称替换
│   └── ComposeModal.vue      ← 修改：修复 popover 定位 + 管理员权限控制
```

### 1.1 constants.ts — 新增默认文件夹映射表

**修改前**：仅定义 `DEFAULT_GROUP_TAG` 常量（1 个字符串）

**修改后**：新增以下内容：
- `DefaultFolderDef` 接口：定义默认文件夹匹配规则
- `DEFAULT_FOLDERS` 常量数组：5 个默认文件夹定义
- `parseTagFields(tag)` 函数：安全解析 tag JSON，提取 type+status
- `isDefaultGroupTag(tag)` 函数：判断 tag 是否属于默认文件夹
- `getDefaultFolderI18nKey(tag)` 函数：获取默认文件夹的 i18n key

### 1.2 i18n/index.ts — 补充国际化 key

**修改前**：缺少 `all_email`、`sketch`、`junk`、`deleted` key

**修改后**：
- 英文新增：all_email, sketch, junk, deleted
- 中文新增：全部邮件, 草稿箱, 广告箱, 已删除

### 1.3 IconNav.vue — 重构 quickGroups

**修改前**：硬编码 2 个默认文件夹 + 字符串精确匹配过滤

**修改后**：使用 DEFAULT_FOLDERS 映射 5 个默认文件夹 + isDefaultGroupTag 解析匹配过滤

### 1.4 ListPanel.vue — group tabs i18n 替换

**修改前**：`{{ group.label }}` 直接显示后端 label

**修改后**：`{{ getFolderLabel(group) }}` 默认文件夹用 i18n 替换

### 1.5 ComposeModal.vue — popover 定位修复 + 权限控制

**修改1**：发件人前缀输入框添加 `:disabled="!isAdmin"`
**修改2**：新增 `isAdmin` 计算属性
**修改3**：`.row-input-wrap` 添加 `position: relative`
