## 二、修改前后对比

### 1. ComposeModal.vue（发件人验证+回信参数+标签式多选+CSV目标字段）

**修改前要点：**
- 无发件人前缀 @ 检查
- 无回信参数（replySender/replyDomain）自动选择发件人域名
- 收件人使用普通 `<input>` 文本框，非标签式多选
- CSV 导入固定追加到 toList

**修改后要点：**
- 新增 `replySender`/`replyDomain` props，回信自动匹配域名
- 新增 `only_prefix` 验证：发件人前缀不能含 @
- 新增至少一个收件人校验（to/cc/bcc 任一非空即可）
- 收件人/抄送/密送改用 `TagInput` 标签式多选组件
- CSV 导入回调增加 `targetField` 参数（'to'|'cc'|'bcc'）

### 2. TagInput.vue（新增）

**功能：**
- 对齐旧前端 `el-select multiple filterable allow-create` 体验
- 回车/逗号/分号添加标签
- 退格删除最后一个标签
- 粘贴多邮箱自动分割
- 去重（不区分大小写）

### 3. CsvImportModal.vue（目标字段选择）

**修改前要点：**
- `emit('import', emails)` 无目标字段参数

**修改后要点：**
- 新增 `targetField` ref（默认 'to'）
- 模板新增目标字段选择下拉框（to/cc/bcc）
- `emit('import', emails, targetField.value)` 传递目标字段

### 4. ContentPanel.vue（iframe 高度自适应）

**修改前要点：**
- iframe 使用固定 `height: 100%; min-height: 400px`
- 无动态高度调整

**修改后要点：**
- 新增 `startHeightWatch()`/`stopHeightWatch()` 定时器检测
- 每 300ms 读取 iframe.contentDocument.body.scrollHeight
- 通过 `watch(email)` 控制定时器生命周期
- `onBeforeUnmount` 清理定时器

### 5. HomeView.vue（回信参数+发送成功跳转）

**修改前要点：**
- `onReply` 仅设置 `replyTo`，不解析发件人信息
- `onEmailSent` 仅关闭弹窗，不跳转

**修改后要点：**
- `onReply` 从 `email.to` 解析当前用户邮箱，提取 `replySender`/`replyDomain`
- `ComposeModal` 传入 `:reply-sender` 和 `:reply-domain`
- `onEmailSent` 发送成功后切换到发件箱 `{"type":1,"status":-1}`

## 三、变更原因与影响

| 变更项 | 原因 | 影响范围 | 风险等级 |
|--------|------|----------|----------|
| 发件人验证补全 | 旧前端有 @ 检查，新前端缺失 | ComposeModal 发送流程 | 低 |
| 回信参数传递 | 旧前端自动选择发件人域名，新前端缺失 | HomeView → ComposeModal | 低 |
| TagInput 标签式输入 | 旧前端用 el-select multiple | ComposeModal 收件人区域 | 中（新组件） |
| CSV 目标字段选择 | 旧前端支持 csvTargetField | CsvImportModal | 低 |
| iframe 高度自适应 | 旧前端有动态高度，新前端固定高度 | ContentPanel 邮件正文 | 低 |
| 发送成功跳转发件箱 | 旧前端发送后自动跳转 | HomeView onEmailSent | 低 |
