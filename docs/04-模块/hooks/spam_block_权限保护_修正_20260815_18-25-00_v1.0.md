## 1. 修改前后代码要点对比

文件：[`server/hooks/spam_block/spam_block.go`](../../../server/hooks/spam_block/spam_block.go)

| 位置 | 修改前 | 修改后 |
|------|--------|--------|
| `SettingsHtml`（index.html 分支之后、save 逻辑之前） | 无权限检查，任何用户可提交配置保存（`saveConfig`） | 新增 `if !ctx.IsAdmin { return "No Access Privileges" }`，非管理员禁止修改插件配置 |

## 2. 变更原因与影响点

- **原因**：母项目安全改进。旧版 `SettingsHtml` 的 save 分支缺少管理员校验，任意登录用户可通过插件配置接口改写 spam_block 的模型 API 地址与过滤阈值，构成配置篡改风险。
- **影响点**：仅拦截非管理员的配置保存请求；管理员与 `index.html` 页面逻辑不变；无接口/数据库变更。
