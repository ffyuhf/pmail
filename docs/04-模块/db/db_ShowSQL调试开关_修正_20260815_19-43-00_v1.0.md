## 2. 变更原因与影响点

- **变更原因**：母项目改进——`logLevel=debug` 时自动打印 SQL 语句，便于数据库问题排查；现有项目固定关闭，排障时需改代码。
- **影响范围**：所有数据库操作日志。默认配置（非 debug 级别）行为与修改前完全一致。
- **接口兼容性**：无影响。
- **性能**：仅 debug 级别额外输出，生产级别零开销。
- **安全**：debug 模式可能输出含用户数据的 SQL 参数（xorm ShowSQL 默认含参数），属调试模式预期行为，生产环境不应启用 debug 级别（与母项目一致）。
- **环境兼容验证**：`services/group` 环境性失败包（config.json 缺失）经 git stash 基线对比，修改前后均为同点位失败（测试代码 `db.Instance.ShowSQL(true)` 对 nil Instance 解引用，预存），本次修改未引入新失败。
