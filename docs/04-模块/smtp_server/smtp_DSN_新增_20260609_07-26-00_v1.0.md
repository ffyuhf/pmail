## 2. 变更原因与影响点

- **变更原因**：阶段二 P1 RFC 6409 邮件提交协议要求 DSN 支持
- **影响范围**：
  - EHLO 响应新增 `DSN` 扩展声明
  - RCPT TO 命令支持 `NOTIFY=` 和 `ORCPT=` 参数
  - MAIL FROM 命令支持 `RET=` 和 `ENVID=` 参数
  - 邮件投递失败时自动生成 RFC 3462 格式退信报告
- **接口兼容性**：完全向后兼容，不使用 DSN 的客户端行为不变
- **性能影响**：仅在使用 DSN 时额外生成退信报告，无性能影响
- **安全防护**：Auto-Submitted 头防止退信循环
