# send ForwardRaw_新增_20260815_18-25-00_v1.0

> **版本**: v1.0 | **日期**: 2026-08-15 | **时间**: 18-25-00 | **作者**: PMail Team | **模块**: smtp_server/send

## 1. 修改前后代码要点对比

文件：[`server/utils/send/send.go`](../../../server/utils/send/send.go)

| 位置 | 修改前 | 修改后 |
|------|--------|--------|
| `Forward` | `b := e.ForwardBuildBytes(ctx, user)`（2 参数）；envelope from 使用 `e.From.EmailAddress`（原发件人身份） | `b := e.ForwardBuildBytes(ctx, user, forwardAddress)`（3 参数）；envelope from 改为 `user.Account@Domains[0]`（本地用户身份）；抽取 `forwardData` 辅助函数 |
| 新增函数 | 无 | `ForwardRaw(ctx, e, rawEmailData, forwardAddress, user)`：以 SMTP 原始字节直接投递，保留原邮件 DKIM 签名；`forwardData`：单地址投递公共逻辑 |

## 2. 变更原因与影响点

- **原因**：母项目改进。旧版转发 envelope from 使用原发件人地址，收件方 SPF 校验必然失败（转发服务器不在原域授权 IP 内），导致转发邮件被拒信或标记为垃圾邮件；新增原始字节转发可保留 DKIM 签名提高送达率。
- **影响点**：
  - `Forward` 行为变化：转发邮件信封发件人变为本地用户（`user.Account@域名`），邮件头 From 亦为本地用户（见 parsemail 修改文档）。
  - `ForwardRaw` 由 [`services/rule/rule.go`](../../../server/services/rule/rule.go) 的 `doForward` 调用（本地转发失败时降级 `Forward`）。
  - 无接口/数据库变更。
