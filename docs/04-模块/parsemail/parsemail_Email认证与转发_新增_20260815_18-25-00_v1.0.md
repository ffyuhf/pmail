# parsemail Email认证与转发_新增_20260815_18-25-00_v1.0

> **版本**: v1.0 | **日期**: 2026-08-15 | **时间**: 18-25-00 | **作者**: PMail Team | **模块**: parsemail

## 1. 修改前后代码要点对比

文件：[`server/dto/parsemail/email.go`](../../../server/dto/parsemail/email.go)

| 位置 | 修改前 | 修改后 |
|------|--------|--------|
| Attachment 结构之后 | 无 | 新增 `EmailAuthentication` 结构体（SPFPassed/DKIMPassed/Dangerous）与 `NewEmailAuthentication` 工厂函数；Dangerous = SPF 与 DKIM 均未通过 |
| `Email` 结构体 | 无 Authentication 字段 | 新增 `Authentication *EmailAuthentication` 字段（收信认证结果，发件邮件为 nil） |
| `NewEmailFromModel` | 直接 `return &Email{...}` | 改为 `ret := &Email{...}`，Type==0（收件）时通过 `NewEmailAuthentication(d.SPFCheck==1, d.DKIMCheck==1)` 恢复认证结果 |
| `ForwardBuildBytes` 签名 | `(ctx, sender)` 2 参数 | `(ctx, sender, forwardAddress)` 3 参数；头部重写：From/Sender=本地转发用户、To=转发目标、Reply-To=原发件人、新增 X-Original-From/X-Forwarded-By/X-Forwarded-To、References/In-Reply-To 关联原邮件、新 Message-ID |
| `ForwardBuildBytes` 结尾 | `return instance.Sign(...)` 无保护 | 新增 `if instance == nil { return b.Bytes() }`，DKIM 未初始化时不 panic |

保留项：原 `Content-Type: text/plain; charset=UTF-8` 与 `Content-Transfer-Encoding: base64` 修复未改动（现有项目自有增强）。

## 2. 变更原因与影响点

- **原因**：移植母项目（Jinnrry/PMail）的邮件认证体系与转发改进。旧版转发以原发件人身份投递且无认证结论对象，转发邮件易被 SPF 拒信/标记伪造。
- **影响点**：
  - `NewEmailFromModel` 变更影响 IMAP/POP3 读取路径（恢复认证结果，仅收件）。
  - `ForwardBuildBytes` 签名变更级联影响 [`utils/send/send.go`](../../../server/utils/send/send.go)（唯一调用方，已同步修改）。
  - HookDTO 序列化自动携带 `Authentication`（插件协议兼容，只增不改）。
  - 无数据库 schema 变更。
