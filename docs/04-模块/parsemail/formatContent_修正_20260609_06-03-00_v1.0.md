## 二、修改前后对比

### 2.1 formatContent 函数 — 新增 Content-Disposition 检查

**修改前**：text/plain 和 text/html 分支未检查 Content-Disposition

```go
case "text/plain":
    testContent, _ := io.ReadAll(entity.Body)
    ret.Text = []byte(stripHTMLTags(string(testContent)))
case "text/html":
    htmlContent, _ := io.ReadAll(entity.Body)
    ret.HTML = []byte(relaxedPolicy.Sanitize(string(htmlContent)))
```

**修改后**：添加 `isAttachment` 检查，附件类型保存到 `ret.Attachments` 而非覆盖正文

```go
disp := strings.ToLower(entity.Header.Get("Content-Disposition"))
isAttachment := strings.Contains(disp, "attachment")

case "text/plain":
    body, _ := io.ReadAll(entity.Body)
    if isAttachment {
        fileName := getFileName(entity, p)
        ret.Attachments = append(ret.Attachments, &Attachment{...})
        return nil
    }
    ret.Text = []byte(stripHTMLTags(string(body)))
case "text/html":
    body, _ := io.ReadAll(entity.Body)
    if isAttachment {
        fileName := getFileName(entity, p)
        ret.Attachments = append(ret.Attachments, &Attachment{...})
        return nil
    }
    ret.HTML = []byte(relaxedPolicy.Sanitize(string(body)))
```

### 2.2 default 分支 — 简化文件名提取

**修改前**：内联文件名提取逻辑

**修改后**：复用新抽取的 `getFileName` 辅助函数

### 2.3 新增 getFileName 辅助函数

```go
func getFileName(entity *message.Entity, p map[string]string) string {
    fileName := p["name"]
    if fileName != "" {
        return fileName
    }
    contentDisposition := entity.Header.Get("Content-Disposition")
    filenameRegex := regexp.MustCompile(`filename\s*=\s*"?([^";]+)"?`)
    matches := filenameRegex.FindStringSubmatch(contentDisposition)
    if len(matches) >= 2 {
        return strings.Trim(strings.TrimSpace(matches[1]), `"`)
    }
    return "no_name_file"
}
```

## 三、变更原因

修复 BUG-3：当邮件包含 text/plain 或 text/html 类型的附件时，
这些附件会被误认为正文，覆盖真正的正文内容。
